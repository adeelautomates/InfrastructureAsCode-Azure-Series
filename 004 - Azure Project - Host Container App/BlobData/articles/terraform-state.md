## What is Terraform State?

Terraform state is the record Terraform maintains of the infrastructure it manages.

Your Terraform configuration describes what you want. The state file records what Terraform currently knows exists.

> Configuration describes the desired infrastructure. State records Terraform's current understanding of it.
